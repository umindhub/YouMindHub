## 概览

YouMindHub 是一款层级式任务与笔记应用，专为深度、结构化的工作而生。整个工作区是一棵树——项目下有阶段，阶段下有任务，任务下有子任务。原生运行于 macOS，采用本地存储。

## 下载

从 **[GitHub Releases](https://github.com/umindhub/MindHub/releases/latest)** 获取最新版本，或访问 **[youmindhub.com/download](https://youmindhub.com/download)**。

## 功能

- **多级嵌套** — 跨无限层级组织工作；一键折叠任意分支。
- **Spotlight 批量编辑** — 选中多个条目，一次性更新状态、标签或截止日期。
- **键盘驱动** — 每个操作都有快捷键。无需离开键盘即可完成创建、移动、缩进和完成。
- **本地存储** — 离线可用，即时启动，无需网络（仅登录和创建 Project 需要）。本地项目、文件和条目数量不限。
- **200 步撤销/重做** — 按文件持久化到磁盘，应用重启后依然有效。
- **30 天保留的回收站** — 永久删除前可恢复。
- **18 款手工精制主题** — 9 款温暖浅色，9 款深邃暗色。
- **云同步** — 在所有设备间同步数据。无论在哪里，随时随地继续你的项目。公开项目免费；私有项目需要 Pro。

## 系统要求

- macOS 14 或更高版本
- Apple Silicon 或 Intel Mac
